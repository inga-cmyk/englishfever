## Variant 1 (recommended)
- **Task:** My grandparents ___ ___ in the same village for fifty years, and they still love it there.
- **Word bank:** have · lived · did · live
- **Answer:** have / lived (only one combination fits)
- **Why (EN):** *For fifty years* and they still live there: the time goes up to now, so use *have* + 3rd form: *have lived*.
- **Why (LV):** *For fifty years*, un viņi joprojām tur dzīvo: laiks turpinās līdz šim brīdim, tāpēc lieto *have* + 3. formu: *have lived*.

## Variant 2
- **Task:** We ___ ___ this car since 2018, and it still runs perfectly.
- **Word bank:** have · had · did · has
- **Answer:** have / had
- **Why (EN):** *Since 2018* and we still own it: up to now, use *have* + 3rd form: *have had*.
- **Why (LV):** *Since 2018*, un mašīna joprojām ir mūsu: līdz šim brīdim, tāpēc lieto *have* + 3. formu: *have had*.
