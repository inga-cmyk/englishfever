# Melnraksts: 36 izvēles uzdevumi formu pāriem (14. novembris)

Brīfa 2. partija: pāri, kuriem izvēles uzdevumu gandrīz nebija. Katrā uzdevumā abas formas ir starp atbildēm, un teikums izšķir, kura der. Otrs aģents tos izlasīja; viņa 8 piezīmes ir iestrādātas.
*would rather + verb / would rather you + past* pārcelts uz 3. partiju (Jūsu 3. lēmums: *would rather* ir B1.2).
