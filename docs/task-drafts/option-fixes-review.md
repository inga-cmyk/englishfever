# Choice tasks: options of equal length and one theme (3 November)

Your rule: all options about one theme (or each about a different one), about the same length, and in *NOT correct* tasks no pair of near-identical sentences that gives the answer away. Every choice task was checked by a script; these were rewritten. Wrong options in form tasks stay ungrammatical.

Also changed: *wish + would* (now a form task), *Water ___ at 100 degrees* (instead of the Earth / boiling water), *Write one sentence that starts with Who…* (instead of *a wh-ever word*), *congratulated Jo ___ passing the exam* (on / about / at / with), *Sales fell. ___, we have decided…* (Therefore / Whereas / Despite / In case), *___ she ___ earlier* (Had / left / Did / leaving).
