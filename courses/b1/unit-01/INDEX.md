# Unit 1: Daily life and free time
Topic: Daily life and free time · Grammar: Present and past tenses
## WordPress build order
1. Upload each file from `dist/h5p/` in **H5P Content → Add New → Upload**. Note each new ID.
2. Create 6 pages from `lesson-*.html` (Custom HTML block). Replace every `[h5p id="uNN-name"]` with the real shortcode `[h5p id="123"]`.
3. Record the audio from `listening/scripts-to-record.md`, upload to the Media Library.
4. In Tutor LMS create 3 quizzes from `tutor-lms/` (see the root README for settings).
