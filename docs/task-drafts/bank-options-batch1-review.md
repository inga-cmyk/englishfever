# Word-bank wrong options, batch 1: tenses (draft for review)

Rule (teacher, 8 November): one word or word group per chip; the wrong chips build **real forms** that do not fit this sentence, so the learner has to know which form the sentence needs. No *We has*, *is get*, or a bare *-ing* without a helping verb.

Every new chip was checked: no other combination of chips gives a correct sentence. Where a time word was missing and another tense would also be correct, the task gets a time word (**new text**; the old version is retired).

**83 tasks change, 21 stay.** Research data: drafts with the same text keep their id (the import updates the options); the 6 tasks with new text and the 2 built-in tasks get a new version. The changelog gets the date, so answers before and after can be compared.
