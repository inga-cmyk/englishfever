# My learning path: topic order (draft for the teacher, 28 October)

The order follows the course books the teacher gave (A2 Grammar units 1–8, the Pre-Intermediate book, the B1 and B2 reference lists in `NOTES-picker-and-levels.md`). Each line is one step on the path. **App topic** is the topic id that trains it; *no topic yet* means the step is shown later, when tasks exist.

How the path uses this order (agreed 28 October):

- **Start**: the placement level. Steps below it are not skipped: each gets a short check (3–5 tasks). Passed: marked done. Not passed: it stays on the path.
- **Done (mastered)** only when all three hold: at least 80% right in the last ~10 answers of that topic; at least two kinds of task (Recognise and Use or Write, one typed answer without a hint); confirmed again on a different day.
- **Every session**: Second Chance that is due, then 2–3 tasks for **lasting mistakes** (an error type from `ERROR-TYPES.md` seen again and again, or on several days; it stays until right on three separate days), then the **current step**, then one look at the next level.
- **No time promises** until the study data show how many sessions people really need.
