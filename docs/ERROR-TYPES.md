# Error types (draft for the teacher, 25 October)

Background list for the personal plans, Second Chance and the placement test. **Learners never see these names**: the system uses them to choose the next task. Each type: the mistake, the correct form, why Latvian speakers make it, level, the grammar reference (Murphy, *English Grammar in Use*, 5th ed., unit), and the app topics that already have tasks for it.

Status: draft, extended with the teacher's additions (25 October). Note: the Drive text of Murphy did not include units 79, 89 and 129–136 in full; those references are by the table of contents and must be checked against the book before tasks are written.

Status: draft. The teacher adds, removes and reorders; nothing is programmed until the list is approved.

| IND-YESNO | *Can you tell me do you live here? · I wonder does she know.* → *Can you tell me if / whether you live here? · I wonder if she knows.* | Latviski: *Vai varat pateikt, vai jūs šeit dzīvojat?* → skolēns atstāj jautājuma formu ar *do*. | B1 | 50 | Indirect questions, Reported questions |

## F. Writing (later, with the AI checker)
These need a whole text, not a single task: comma splices (*Arvīds seems a nice guy, he is smart*), run-on sentences, unclear contrast between two ideas, misplaced time phrases, noun phrases without a link (*rich knowledge base amazing experience*). They stay out of the personal plans until the AI checker can read free writing.

## Explanations: Latvian reasons only when they are real (teacher, 25 October)
Many mistakes have no link with Latvian (*call to me*, *join to the team*: Latvian has no preposition there either). Then the feedback does not invent one; it says *Tipiska kļūda* and shows the English pattern. A Latvian comparison is used only where the Latvian form really leads to the mistake.

## How the system will recognise a type (for later)
- Each wrong option of a choice task and each specific hint of a typed task gets one code.
- The placement test gets 1–2 tasks per type at the learner's level, so the first plan can start from real mistakes.
- A type goes into personal plans only when it has enough tasks at each support level (about 10–15), so the learner does not meet the same tasks again and again.

## Mistakes from learners' writing (planned)
The teacher will send a list of mistakes collected from written work. Each one is classified into a type above (or a new type), checked against the grammar books, and used as a wrong option or a hint pattern. The feedback then says, in one short line: *Tā bieži saka, bet angliski: …* (EN: *A common mistake. In English: …*). The list should have: the mistake as written, the correction, the level, and a note. Learner names are not stored in the app or in this repository.

First list received 25 October (34 mistakes); classified into the types above (ARTICLE, THE, PLURAL, POSSESSIVE, NO-VERB, BE, PAST-FORM, 3S, AGREE, DEP-PREP, PATTERN, TWO-OBJ, BASE, NEG-INF, COMPARE, REL-ORDER, REL-WHICH, CONTRAST, NP-ORDER, F).
